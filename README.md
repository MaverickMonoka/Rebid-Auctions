# RE:BID

Independent auction marketplace for returned, pre-owned, demo, refurbished and clearance goods.

## Product
- Responsive web marketplace + installable PWA
- Timed auctions, reserve prices and bid increments
- Condition grading and transparent item disclosures
- Watchlists, bidder accounts, checkout and collection/delivery
- Admin inventory and auction operations

## Stack
Next.js 15, React 19, TypeScript, Tailwind CSS, Supabase-ready backend.

No retailer affiliation is implied by this product.
